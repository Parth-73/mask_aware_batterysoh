# Four-model benchmark audit and implementation plan

Audited source commit: cdfd29167afb76fdd7c9513c9132bc97efc105b0.

The workspace initially contained raw data only. A sparse checkout retrieves the existing repository without duplicating raw measurements or changing historical artifacts. Existing inspection, reconstruction, extraction, analysis, training, feature definitions/sets, quality tables, historical reports and tests are reviewed before implementation.

1. Reuse `training.dataset.audit_source` and `cycle_reasons`; cross-check labels, capacity integrals/counters, rejection lists, and timestamps. Use `build_windows` as the reference oracle for an optimized equivalent window builder; differential tests require identical arrays, metadata, and all rejection reasons. Preserve the nine-feature complete-case cohort for matched feature comparisons. Preserve definitions unchanged. Hash the local raw inventory and compare content hashes with the historical inventory; do not assert a full new reconstruction was run.
2. Use seven outer battery folds, with inner validation the next battery in the fixed ordered list (wrapping around). Historical split is separate. StandardScaler fits eligible inner-training cycles only. Windows stay in one source sheet with consecutive original ordinals, no rejected rows, no overlap, and gaps at most 3600 seconds. Length ablations use the length-20 target intersection.
3. Add vanilla 64-unit LSTM, compact Transformer, and LSTM/CNN encoders with an identical latent-degradation head. A nonnegative latent D and bounded correction distinguish a soft irreversible-aging hypothesis from observed rebounds. Penalize decreasing D on adjacent chronological training windows and correction magnitude. D is **not guaranteed globally monotone**, nor identifiable as physical capacity loss. No cycle/battery ID enters any encoder.
4. Use fixed physics weight 0.1 and correction regularization 0.1 (singleton predefined coefficient space; no outer-dependent tuning), plus both weights zero as the controlled ablation. Select checkpoints by inner-validation MSE. All architecture and feature comparisons share cohorts and seeds. Select an overall recommendation by mean inner-validation RMSE over folds/seeds; outer macro-battery RMSE is descriptive performance, never a tuning signal.
5. Implement deterministic FP32 training, atomic artifacts, full optimizer/scheduler/RNG resume, manifests with source/data/environment hashes, unit/integration tests, and four smoke runs before benchmarks. CUDA is available; avoid AMP for this small numerically sensitive task.
6. Run the full 200-epoch budget when feasible. A separately identified reduced-budget run is permitted, with all three seeds and seven outer folds; never mix smoke/reduced/full results. Compare three/nine features on vanilla LSTM and zero-constraint variants on both PINNs. Length 10/20 ablations are vanilla LSTM on matched length-20 targets, including a matched length-5 control. Historical runs are separately identified.
7. Generate complete prediction/metric tables, seed and battery macro summaries, subgroup counts, 300-DPI/vector figures, JSON and Markdown reports. State matrix completeness and unavailable experiments explicitly.

Rest assessment: exported aggregate features contain post-charge 60-second voltage relaxation, not verified preceding rest duration or rest event timestamps. Inter-cycle recording gaps are insufficient evidence. Rest duration remains unavailable (NaN); no six-feature/rest-event experiment is justified without a dedicated raw-state audit. CX2_3/8 protocol-transfer comparability is unverified and CX2_32 has no validated labels; none enters supervised evaluation.

Scientific limitations: seven previously explored cells; related protocols and capacity-rate confounding; prior feature screening; conservative complete-case selection; overlapping windows are not independent replicates. Seed SD is optimization variability, not a battery-population confidence interval. No Neural Prony model is implemented.
